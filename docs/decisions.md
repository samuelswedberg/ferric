# Decisions

- 2026-11-22 · Store `shuffle: Option<bool>` and `repeat: Option<RepeatMode>` separately on `PlayerState` with an atomic `Command::SetPlaybackMode { shuffle, repeat }`, and add `Track.artist_id`. Why: mirrors Spotify's actual Web API state without losing fidelity if toggled in the Spotify desktop app, while letting the UI cycle cleanly in one IPC round-trip with a 2s poll hold against stale flicker. Alternatives rejected: separate `SetShuffle`/`SetRepeat` IPC commands (risked split state/double toasts on cycle transitions) or collapsing Spotify's two flags in Rust (would hide Spotify's exact state).
- 2026-11-22 · Artist text opens the Spotify artist page (direct `artist_id` with artist-search fallback), single Shuffle/Repeat button uses a 3-state cycle (`Shuffle -> Repeat context -> Repeat track -> Shuffle`, displaying dimmed Off if both start off), and all three modes (Full, Card, Strip) share the new key order and click targets. Why: confirmed interactively with Sam for T0002. Alternatives rejected: moving the album link onto artist text, 4-state cycle including Off, or keeping Play/Pause in Strip mode.
